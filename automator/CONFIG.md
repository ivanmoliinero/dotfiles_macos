# SETUP OF AUTOMATOR WORKFLOWS
## Step by step runbook
1. Run the deploy script whilst being in the `automator` dir.
2. Open System Settings --> Keyboard --> Keyboard Shortcuts --> General --> 'the names of the services'
3. Adjust the shortcuts as desired.

## Configured shortcuts
|Workflow|Description|Shortcut|
|---|---|---|
|open_ghostty_in_finder|Opens Ghostty terminal in the actual directory of finder|Ctrl+T|
