# Neovim config
This guide helps to configure neovim with LazyVim to have the same color scheme as Ghostty.

## LazyVim installation
To install the new plugin, run:
```bash
git clone https://github.com/LazyVim/starter ~/.config/nvim
```

## Config
Create the hard/soft links to the `~/.config/nvim/lua/config/lazy.lua`and `~/.config/nvim/lua/plugins/colorscheme.lua`.
